# Intent: Multi-Agent AI SDLC Expansion (Claude Code, Codex, Cursor, Copilot & Antigravity)

**Author**: Antigravity SDLC Lead & User  
**Date**: 2026-09-04  
**Status**: Approved  
**Target Milestone**: v1.1-evolution (Milestone 011)  

---

## 1. Problem Statement

The AI-Native SDLC Starter Template was initially optimized for Google Antigravity (using `GEMINI.md`, `.gemini/skills/`, `.gemini/agents/`, and `GeminiReviewer`). However, modern software engineering teams use heterogeneous agentic coding tools across their developer workflows:
- **Anthropic Claude Code** (CLI agent using `CLAUDE.md`, `.claude/commands/`, custom slash workflows)
- **OpenAI Codex / ChatGPT / Codex CLI** (leveraging `AGENTS.md` and `CODEX.md`)
- **Cursor & Windsurf IDEs** (using `.cursorrules` and `.cursor/rules/*.mdc`)
- **GitHub Copilot** (using `.github/copilot-instructions.md`)

When engineering teams attempt to adopt this starter template with tools other than Antigravity, they lack:
1. Native system instruction / directive files tailored to each tool's discovery conventions.
2. Tool-native slash commands and workflows (e.g. `/grill-me`, `/verify`, `/review-pr` in Claude Code).
3. Universal agent configuration standard (`AGENTS.md`) recognized across all emerging coding agents.
4. Multi-provider review agent capabilities (the autonomous ReviewAgent was tied solely to Gemini).

- **Impact & Urgency**: Expanding the AI SDLC template to universally support all major coding tools eliminates platform lock-in, enabling any team to run rigorous, spec-driven, test-enforced development regardless of their AI toolchain.

---

## 2. Proposed Outcome

1. **Universal Directives Harmonization**:
   - Provide first-class directives for all major tools: `CLAUDE.md` (Claude Code), `AGENTS.md` (Open Agent Standard), `CODEX.md` (OpenAI Codex), `.cursorrules` + `.cursor/rules/sdlc.mdc` (Cursor), and `.github/copilot-instructions.md` (GitHub Copilot), perfectly aligned with existing `GEMINI.md`.
2. **Claude Code Native Commands**:
   - Deliver `.claude/commands/` providing native slash commands: `/grill-me`, `/spec-architect`, `/verify`, `/review-pr`, and `/new-intent`.
3. **Multi-Provider ReviewAgent**:
   - Upgrade `ReviewAgent` semantic reviewer to support Anthropic Claude, OpenAI, and Google Gemini backends via standard library HTTP drivers without heavyweight dependencies.
   - Provide CLI and environment configuration for provider selection (`--provider`, `LLM_PROVIDER`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`).
4. **Universal Bootstrap Scaffolding**:
   - Update `bootstrap.sh` and `scripts/bootstrap.sh` to scaffold all agent directives, skills, and slash commands simultaneously by default.
5. **Comprehensive Multi-Agent Onboarding**:
   - Update `README.md` and `ONBOARDING.md` with step-by-step guides for developers using Antigravity, Claude Code, OpenAI Codex, Cursor, and GitHub Copilot.

---

## 3. Affected Users & Systems

- **Target Personas / Users**:
  - Developers and teams using Claude Code CLI.
  - Developers using Cursor, Windsurf, or VS Code with GitHub Copilot.
  - Developers using OpenAI Codex / ChatGPT agent environments.
  - Developers using Google Antigravity.
- **Affected Systems / Services**:
  - Root directive files (`CLAUDE.md`, `AGENTS.md`, `CODEX.md`, `.cursorrules`, `.github/copilot-instructions.md`).
  - Claude commands directory (`.claude/commands/`).
  - ReviewAgent architecture (`src/agent/review_agent.py`, `src/agent/semantic_reviewer.py`, `src/cli.py`).
  - Bootstrap scripts (`bootstrap.sh`, `scripts/bootstrap.sh`).
  - Documentation (`README.md`, `ONBOARDING.md`).

---

## 4. Constraints & Boundaries

- **Zero Heavyweight Dependencies**: Multi-provider semantic reviewers for Anthropic, OpenAI, and Gemini must use standard library `urllib.request` and `json` to prevent dependency bloat.
- **Strict Backward Compatibility**: Existing Antigravity workflows (`GEMINI.md`, `.gemini/`, `--use-gemini` CLI flags) must continue functioning without regression.
- **Unbroken Chain & Single Verification**: All SDLC gate hooks (`.githooks/`) and `make verify` must pass cleanly.
- **Single Source of Truth**: Core SDLC principles (intent ➔ spec ➔ plan ➔ tdd ➔ verify ➔ review) must remain strictly consistent across all agent directive files.

---

## 5. Open Questions & Assumptions

1. *Q: Should developers have to choose one tool during bootstrapping or have all tool files generated?*  
   *Decision*: Universal simultaneous support. All major tool directives and slash commands are generated by default so developers can switch between tools seamlessly in the same repository.
2. *Q: How does ReviewAgent pick the provider if multiple API keys are present?*  
   *Decision*: Explicit `--provider` flag > `LLM_PROVIDER` environment variable > fallback priority order: Anthropic (`ANTHROPIC_API_KEY`) / OpenAI (`OPENAI_API_KEY`) / Gemini (`GEMINI_API_KEY`).
