# Stage 5: PR Review & Audit Reports (`reviews/`)

This directory houses version-controlled, evidence-based **Stage 5 PR Review Audit Reports** generated by the autonomous `ReviewAgent`, the `auditor` subagent, and human code owners.

---

## 📋 Schema & Structure

Each review report follows [`templates/review.template.md`](../../templates/review.template.md):
- **Linked Plan & Spec**: Full traceability to `plans/NNN-*.md` and `specs/NNN-*.md`.
- **Verdict**: `PASS`, `CHANGES_REQUESTED`, or `BLOCKED`.
- **Findings by Severity Tier**:
  - 🚨 **Tier 1: Blocker**: Broken functional behavior, security/secret leaks, gutted tests.
  - ⚠️ **Tier 2: Important**: Unhandled edge cases, plan deviations, anti-shortcut `TODO` stubs.
  - 💡 **Tier 3: Nit**: Readability and styling suggestions.
- **Plan Fidelity Matrix**: Evidence mapping each task step to `file:line`.
- **Governance Sign-off**: Automated verification status & Human Code Owner approval.

---

## 🤖 Generating a Review Report

```bash
# Review a single file:
python3 -m src.cli review <file_path> [--spec <spec_file>] [--output <out.md>]

# Review a full branch diff against base:
python3 -m src.cli review-pr [--base origin/main] [--spec <spec_file>] [--output reviews/NNN-feature.md]
```
